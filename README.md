# คู่มือการติดตั้งและใช้งานระบบบริหารสัญญา (Contract Management System: CMS)
## ฝ่ายสาธารณูปโภค ส่วนการโยธา สำนักช่าง เทศบาลนครระยอง

ระบบนี้พัฒนาขึ้นเพื่อเพิ่มประสิทธิภาพการกำกับติดตามโครงการจ้างก่อสร้าง/บริการของฝ่ายสาธารณูปโภค สอดคล้องตาม **ระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560** โดยทำงานผ่าน Google Sheets, Google Drive, และ Google Apps Script (GAS)

## 1. การจัดเตรียม Google Sheets (ฐานข้อมูล)

สร้าง Google Sheets ใหม่ขึ้นมา 1 ไฟล์ (เช่น ตั้งชื่อว่า `DB_ระบบบริหารสัญญา_ฝ่ายสาธารณูปโภค_2569`)

สร้างชีตย่อยทั้งหมด **3 ชีต** โดยตั้งชื่อแท็บชีตให้ตรงตามนี้ทุกตัวอักษร:

### 1.1 ชีตที่ 1: `ContractMaster` (ตารางข้อมูลสัญญาหลัก)
กำหนดแถวที่ 1 (Header) ดังนี้:

| คอลัมน์ | ชื่อฟิลด์ (Header) | คำอธิบาย | ตัวอย่างข้อมูล |
| :--- | :--- | :--- | :--- |
| **A** | `ContractID` | รหัสสัญญาภายใน | CTR-69-001 |
| **B** | `ContractNo` | เลขที่สัญญาตาม พ.ร.บ. | 12/2569 |
| **C** | `ProjectName` | ชื่อโครงการ | โครงการก่อสร้างปรับปรุงระบบระบายน้ำและบาทวิถี ถนนตากสินมหาราช |
| **D** | `Contractor` | ผู้รับจ้าง (หจก./บจก.) | ห้างหุ้นส่วนจำกัด ระยองการโยธา 2024 |
| **E** | `Budget` | งบประมาณ/ราคากลาง (บาท) | 2500000 |
| **F** | `ContractAmount` | วงเงินค่าจ้างตามสัญญา (บาท) | 2380000 |
| **G** | `PenaltyRate` | อัตราค่าปรับต่อวัน (เช่น 0.001 หรือ 0.1%) | 0.001 |
| **H** | `StartDate` | วันเริ่มต้นสัญญา (YYYY-MM-DD) | 2026-05-01 |
| **I** | `EndDate` | วันสิ้นสุดสัญญา (YYYY-MM-DD) | 2026-10-31 |
| **J** | `Status` | สถานะโครงการ (`Active` / `Completed`) | Active |
| **K** | `ResponsibleEngineer` | นายช่างผู้ควบคุมงาน | นายสมชาย ใจมั่น (วิศวกรโยธาชำนาญการ) |

> 💡 **หมายเหตุ:** หากเปิดใช้งานระบบครั้งแรกและยังไม่ได้สร้างชีต ฟังก์ชัน `initDatabase()` ใน `Code.gs` จะสร้างชีตและข้อมูลตัวอย่างให้โดยอัตโนมัติ

### 1.2 ชีตที่ 2: `DailyLogs` (ตารางบันทึกตรวจงานประจำวัน)
กำหนดแถวที่ 1 (Header) ดังนี้:

| คอลัมน์ | ชื่อฟิลด์ (Header) | คำอธิบาย |
| :--- | :--- | :--- |
| **A** | `LogID` | รหัสบันทึก (ระบบสร้างให้อัตโนมัติ เช่น LOG-690825-163000) |
| **B** | `ContractNo` | เลขที่สัญญา |
| **C** | `LogDate` | วันที่ตรวจงานหน้างาน (YYYY-MM-DD) |
| **D** | `Weather` | สภาพอากาศ (ปกติ/แจ่มใส, มีเมฆมาก, ฝนตก, พายุ) |
| **E** | `LaborCount` | จำนวนแรงงานปฏิบัติงาน (คน) |
| **F** | `MachineryUsed` | เครื่องจักรกลที่ใช้ |
| **G** | `ProgressPercent` | ความคืบหน้าสะสม (%) |
| **H** | `Issues` | ปัญหาและอุปสรรคที่พบ |
| **I** | `Solution` | แนวทางการแก้ไข/ข้อสั่งการ |
| **J** | `PhotoUrl` | ลิงก์รูปภาพใน Google Drive |
| **K** | `LocationGPS` | พิกัดสถานที่ตรวจงาน (ละติจูด, ลองจิจูด) |
| **L** | `InspectorName` | ชื่อผู้ควบคุมงานผู้บันทึก |
| **M** | `Timestamp` | วันและเวลาที่บันทึกข้อมูลเข้าระบบ |

### 1.3 ชีตที่ 3: `Inspections` (ตารางส่งมอบและตรวจรับงานงวด)
กำหนดแถวที่ 1 (Header) ดังนี้:

| คอลัมน์ | ชื่อฟิลด์ (Header) | คำอธิบาย |
| :--- | :--- | :--- |
| **A** | `InspectionID` | รหัสการตรวจรับ (เช่น INSP-690825-101500) |
| **B** | `ContractNo` | เลขที่สัญญา |
| **C** | `PeriodNo` | งวดงานที่ส่งมอบ (เช่น งวดที่ 1) |
| **D** | `DeliveryDate` | วันที่ผู้รับจ้างส่งมอบงาน |
| **E** | `CommitteeMeetDate` | วันนัดตรวจรับของคณะกรรมการ |
| **F** | `InspectionResult` | ผลการตรวจรับ (ผ่าน / มีงานแก้ไข / ไม่ผ่าน) |
| **G** | `Remarks` | รายละเอียด/ข้อสังเกตของคณะกรรมการ |
| **H** | `InspectorSign` | ประธานกรรมการ / กรรมการผู้ตรวจรับ |
| **I** | `Status` | สถานะสัญญาหลังตรวจรับ (`Active` / `Completed`) |
| **J** | `Timestamp` | วันและเวลาที่ประทับตราบันทึก |

## 2. การจัดเตรียมโฟลเดอร์ Google Drive (จัดเก็บรูปภาพ)

1. เข้าไปที่ **Google Drive** ของหน่วยงาน/ส่วนตัว
2. สร้างโฟลเดอร์ใหม่ ตั้งชื่อว่า: `ภาพถ่ายตรวจงาน_เทศบาลนครระยอง`
3. คลิกขวาที่โฟลเดอร์ -> เลือก **แชร์ (Share)**
4. ในส่วน **การเข้าถึงทั่วไป (General access)** ให้เปลี่ยนเป็น:
   - **"ทุกคนที่มีลิงก์ (Anyone with the link)"**
   - สิทธิ์: **"ผู้มีสิทธิ์อ่าน (Viewer)"**
5. คัดลอก **Folder ID** จาก URL ของโฟลเดอร์:
   ```
   https://drive.google.com/drive/folders/1Fy4qA_k4YAMK8O6vlxuU88_TupK4ZYTe
                                          ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                          (คัดลอกส่วนนี้คือ Folder ID)
   ```

## 3. การนำโค้ดขึ้นระบบ Google Apps Script (Deploy Web App)

### ขั้นตอนที่ 1: เปิด Apps Script จาก Google Sheets
1. ในหน้า Google Sheets ที่เตรียมไว้ ให้คลิกที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
2. ตั้งชื่อโปรเจกต์ด้านบน เช่น `CMS_เทศบาลนครระยอง`

### ขั้นตอนที่ 2: วางโค้ด Backend (`Code.gs`)
1. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด
2. คัดลอกโค้ดทั้งหมดจากไฟล์ `Code.gs` ที่เตรียมไว้มาวาง
3. ตรวจสอบการตั้งค่าตัวแปร `CONFIG` ด้านบนสุด:
   ```javascript
   const CONFIG = {
     SPREADSHEET_ID: "", // ปล่อยว่างไว้ หากสคริปต์นี้ผูกอยู่กับ Google Sheets โดยตรง
     DRIVE_FOLDER_ID: "1Fy4qA_k4YAMK8O6vlxuU88_TupK4ZYTe", // นำ Folder ID จากข้อ 2 มาใส่
     OFFICER_EMAILS: "procurement@rayongcity.go.th", // อีเมลรับแจ้งเตือน
     ...
   };
   ```

### ขั้นตอนที่ 3: เพิ่มไฟล์ Frontend (`Index.html`)
1. ในหน้าต่าง Apps Script เมนูด้านซ้าย ข้างๆ คำว่า "ไฟล์ (Files)" ให้กดปุ่ม **+** -> เลือก **HTML**
2. ตั้งชื่อไฟล์ว่า `Index` (ไม่ต้องพิมพ์ .html)
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `Index.html` มาวางทับโค้ดเดิมทั้งหมด
4. กดปุ่ม **บันทึกโครงการ (Save project)** 💾

### ขั้นตอนที่ 4: การนำไปใช้งาน (Deploy as Web App)
1. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)** สีน้ำเงินมุมขวาบน -> เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนรูปเฟือง ⚙️ ข้าง "เลือกประเภท" -> เลือก **เว็บแอป (Web app)**
3. ตั้งค่าการเผยแพร่ดังนี้:
   - **คำอธิบาย (Description):** `ระบบบริหารสัญญา v1.0 เทศบาลนครระยอง`
   - **เรียกใช้ในฐานะ (Execute as):** **ฉัน (Me / อีเมลของคุณ)** *(สำคัญมาก เพื่อให้มีสิทธิ์เขียนชีตและอัปโหลด Drive)*
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(เพื่อให้ผู้ควบคุมงานเปิดผ่านมือถือหน้างานได้โดยไม่ต้องตั้งสิทธิ์รายคน)*
4. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)**
5. ในการ Deploy ครั้งแรก ระบบจะขอสิทธิ์เข้าถึง (Authorization):
   - คลิก **ตรวจสอบสิทธิ์ (Review permissions)**
   - เลือกบัญชี Google ของท่าน
   - หากขึ้นหน้าจอเตือนความปลอดภัย "Google ยังไม่ได้ยืนยันแอปนี้" ให้คลิก **ขั้นสูง (Advanced)** -> คลิก **ไปที่ [ชื่อโปรเจกต์] (ไม่ปลอดภัย)**
   - คลิก **อนุญาต (Allow)**
6. คัดลอก **URL เว็บแอป (Web app URL)** เพื่อนำไปแจกจ่ายให้เจ้าหน้าที่และผู้ควบคุมงานใช้งาน หรือสร้างเป็น QR Code ได้ทันที!

## 4. การใช้งานระบบและฟีเจอร์หลัก

### 4.1 แดชบอร์ดสรุปผลและไฟจราจร (Dashboard)
- **🟢 สีเขียว (ปกติ):** สัญญาดำเนินงานตามปกติ เหลือระยะเวลาเกิน 15 วัน
- **🟡 สีเหลือง (ใกล้ครบกำหนด):** สัญญาเหลือระยะเวลาน้อยกว่า 15 วัน ระบบจะขึ้นป้ายเตือนให้เร่งรัดติดตามงาน
- **🔴 สีแดง (เกินกำหนด/คิดค่าปรับ):** สัญญาสิ้นสุดลงแล้วแต่ยังไม่ส่งงาน ระบบคำนวณค่าปรับรายวันอัตโนมัติ และเตือนการออกหนังสือแจ้งปรับภายใน 7 วัน (ตามระเบียบฯ ข้อ 181) หากค่าปรับเกิน 10% จะเตือนเกณฑ์บอกเลิกสัญญา (ตามระเบียบฯ ข้อ 183)

### 4.2 บันทึกตรวจงานประจำวัน (Daily Log) สำหรับนายช่างผู้ควบคุมงาน
- เปิดผ่านเบราว์เซอร์บนมือถือ (Safari, Chrome, Line Browser)
- เลือกโครงการ -> กรอกแรงงาน เครื่องจักร % ความคืบหน้า
- **กล้องมือถือ:** แตะปุ่มถ่ายรูป ระบบจะเปิดกล้องหลังมือถือทันที พร้อมลดขนาดไฟล์ภาพอัตโนมัติก่อนส่ง
- **พิกัด GPS:** แตะปุ่ม "ดึงพิกัด GPS" ระบบจะระบุละติจูด-ลองจิจูดจริงหน้างานพร้อมลิงก์ Google Maps
- กด "บันทึก" ข้อมูลจะวิ่งเข้า Google Sheets และรูปภาพจะเข้า Google Drive ทันที

### 4.3 ส่งมอบและตรวจรับงาน (Inspection Log) สำหรับคณะกรรมการ
- บันทึกงวดงานที่ส่งมอบ และผลการตรวจรับ
- คำนวณนับถอยหลัง **SLA 3 วันทำการ** (ระเบียบฯ ข้อ 176(5))
- ระบบส่งอีเมลแจ้งเตือนคณะกรรมการและเจ้าหน้าที่พัสดุโดยอัตโนมัติ

## 5. แนวทางแก้ไขปัญหาทั่วไป (Troubleshooting)

| ปัญหาที่พบ | สาเหตุที่เป็นไปได้ | แนวทางแก้ไข |
| :--- | :--- | :--- |
| **1. เปิดดูรูปภาพจาก Google Drive ไม่ได้ / ขึ้นขอสิทธิ์** | สิทธิ์ของโฟลเดอร์ Google Drive ยังเป็นส่วนตัว | เข้าไปที่ Google Drive -> คลิกขวาโฟลเดอร์รูปภาพ -> แชร์ -> เปลี่ยนเป็น **"ทุกคนที่มีลิงก์ (Viewer)"** |
| **2. กดปุ่มดึงพิกัด GPS แล้วไม่ทำงาน / ขึ้นปฏิเสธ** | เบราว์เซอร์หรือมือถือปิดกั้นการเข้าถึงตำแหน่ง (Location Permission) | เข้าไปที่การตั้งค่าเบราว์เซอร์ของมือถือ -> สิทธิ์เข้าถึงของเว็บไซต์ (Site Settings) -> อนุญาต **ตำแหน่ง (Location)** |
| **3. กล้องมือถือไม่เปิดเมื่อแตะถ่ายรูป** | เบราว์เซอร์ไม่รองรับแท็ก capture หรือไม่ได้ให้สิทธิ์กล้อง | แตะปุ่มเลือกไฟล์ ระบบจะให้เลือกว่าจะ "ถ่ายรูปด้วยกล้อง" หรือ "เลือกจากคลังรูปภาพ" |
| **4. มีการแก้ไขโค้ดแต่หน้าเว็บไม่เปลี่ยนแปลง** | ไม่ได้ทำ New Deployment หลังแก้ไขโค้ด | ใน Apps Script ต้องคลิก **Deploy -> Manage deployments -> ดินสอแก้ไข -> เลือกเวอร์ชันใหม่ (New version) -> Deploy** |
| **5. วิธีตรวจสอบข้อผิดพลาดของระบบ (Debugging)** | ข้อมูลไม่เข้าชีต หรือมี Error | ใน Apps Script ให้คลิกเมนูทางซ้าย **บันทึกการทำงาน (Executions)** เพื่อดูประวัติ Log การรันย้อนหลังอย่างละเอียด |
